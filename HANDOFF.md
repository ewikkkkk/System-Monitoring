Production database name is not supplied yet. Use the METS Hub application database; apply numbered migrations 001–005 in order with a migration ledger owned by the host. Schema: monitoring. ## 5. Which routes must be restricted, and to whom?
All /api/system-monitoring routes require authenticated monitoring-team access at router level. GET /tasks, GET /people, GET /tasks/:id/history, GET /deployments: authorized monitoring viewers. POST /tasks, PUT /tasks/:id, PATCH /tasks/:id/status: developers, testers, and team leads. POST /deployments (Deployment/Fix/Revert): release managers and team leads. Apply method-level policy in host router middleware. No client identity or local authorization tables are accepted.
